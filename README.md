# Modern Minimalist Portfolio Website

A professional portfolio website with a modern minimalist aesthetic featuring clean lines, ample white space, subtle animations, and a focus on typography. The design uses a monochromatic color scheme with one accent color for emphasis.

## Features

- **Responsive Design**: Works seamlessly on all devices
- **Light/Dark Mode**: Toggle between light and dark themes
- **Smooth Animations**: Subtle hover effects and transitions between sections
- **Project Filtering**: Filter projects by category
- **Interactive Elements**: Animated particles background, skill progress bars
- **Contact Form**: Functional contact form with validation
- **Optimized Performance**: Fast loading times and optimized images

## Sections

- **Hero**: Full-screen introduction with animated background
- **About**: Personal bio with image gallery
- **Expertise**: Core competency areas
- **Experience**: Professional timeline
- **Projects**: Featured work with filtering options
- **Skills**: Technical skills with visual indicators
- **Contact**: Contact form and information

## Technologies Used

- HTML5
- CSS3 (Custom variables, Flexbox, Grid)
- JavaScript (Vanilla JS)
- Particles.js for background animation
- Font Awesome for icons
- Google Fonts (Inter)

## Setup and Customization

1. Replace placeholder images in the `images` folder with your own photos
2. Update personal information in `index.html`
3. Modify project details and links
4. Add your own skill logos to `images/skills` directory
5. Update contact information

## Deployment

This site can be deployed to GitHub Pages by:

1. Creating a GitHub repository named `username.github.io`
2. Pushing this code to that repository
3. GitHub Pages will automatically serve the site at `https://username.github.io`
